# Web版と同じ見た目でアプリを利用する

> ステータス: 15回のレビューと修正、ブラウザ比較・操作テストを実施済み。実機での描画差は別途確認対象。

## ストーリー

利用者として、Web版からネイティブアプリに移っても、画面の見た目と操作位置が同じで迷わず利用したい。

## 動作確認の手順

1. 比較専用のseedを作り、同じ利用者でWeb版とExpo版にログインする。
   - データ量やカードの違いを見た目の差と取り違えない。
2. 表示領域を390×844に揃えて各画面を撮影する。
   - 背景、フォント、ヘッダー、残高、タブがWeb版と同じ仕様になる。
3. パック、コレクション、対戦、マーケット、マイページと配下の画面を比較する。
   - 要素の順番、幅、高さ、余白、色、角丸、アイコン、文言が揃う。
   - シート、確認ダイアログ、空の状態、エラー状態も比較する。
4. 小さい画面と大きい画面でも確認する。
   - 横にはみ出さず、カードや操作がタブに隠れない。
5. 実際に開封、編成、強化、購入・入札、還元、ログアウトを行う。
   - 見た目を合わせたことで既存の操作が壊れていない。

## データの持ち方

- Web版とネイティブ版で同じAPIと比較専用利用者を使う。
- 比較画像は `output/native-parity/` に保存し、実行手順とレビュー記録は開発ドキュメントに残す。

## 対応するテスト

- `scripts/native-parity.mjs`: 同一条件でのWeb・Expoの画面撮影。
- `tests/native/app.spec.ts`: ブラウザーによる操作の回帰確認。
- `bun run test`: 既存ストーリーに対応するAPI・共通ロジックの回帰確認。

比較の結果は [レビュー記録](../development/native-parity-review.md) に残す。
