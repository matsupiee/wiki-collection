# pt を払って確定ガチャを開ける

> ステータス: 実装済み

## ストーリー

高レアリティのカードを集めたいユーザーとして、希望する最低レアリティを選び、5枚まとめて入手したい。

## 動作確認の手順

1. `bun run db:seed` 後に `hanako@example.com` でログインし、ダブルレア確定ガチャを選ぶ。
   - 選択画面と開封画面で、帯と圧着部が銀色に見える。
   - 5枠ともダブルレア99%、レジェンド1%で抽選する。消費する100ptと現在の残高が表示される。
2. 「100pt」の下の「開封する」を押し、開封結果を見る。
   - 5枚すべてがダブルレアまたはレジェンドで、残高が100pt減る。
3. パック選択に戻り、レジェンド確定ガチャを選んで開ける。
   - 選択画面と開封画面で、帯と圧着部が金色に見える。
   - 5枚すべてがレジェンドで、残高が500pt減る。
4. pt の履歴を開く。
   - 開封ごとの消費額が記録され、無償ptから先に使われる。
   - → [pt の履歴を確認する](./coin-history.md)
5. ポイント残高が0の `taro@example.com` で有料パックを選び、「開封する」を押す。
   - 「ポイントが不足しています」と表示される。必要なポイントの説明の下にある「ポイント購入へ」で購入画面に進める。

## データの持ち方

- `pack` に価格と枚数、`pack_slot_rate` に各枠で排出できるレアリティを登録する。
- 対象レアリティに有効なカードがなければ開封を中止し、残高と開封履歴を維持する。

## 対応するテスト

- `packages/api/src/test/guaranteed-packs.integration.test.ts` で販売切り替え、各5枚のレアリティ、消費額、候補不足時の処理を確認する。
- `packages/api/src/routers/consumer/pack/open/handler.integration.test.ts` で無償ptの優先消費、残高不足、同時開封を確認する。
