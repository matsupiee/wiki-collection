# pt を払ってジャンルパックを開ける

> ステータス: 実装済み

## ストーリー

特定のジャンルのカードを集めているユーザーとして、pt を払ってそのジャンルのカードだけが出るパックを開けたい。
狙っているカードが出やすいパックなら、集める近道になる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `hanako@example.com` でログインし、パック選択画面で天体パックを選ぶ。
   - パックの下に「150pt」と出る。
2. 天体パックの詳細画面を開く。
   - 「出やすいカード」にブラックホールと月が出る。
   - 「これにする 150pt」ボタンと、いまの残高が出る。
3. 「これにする 150pt」を押す。
   - 「150pt を使います」「開封後の残高」を示す確認ダイアログが出る。
4. 「開封する」を押す。
   - 開封画面に移動する。5枚はすべて天体ジャンルのカードで、5枚目はレア以上。
5. 開封結果まで進み、ヘッダーの残高を見る。
   - 150pt 減っている。
6. 「pt の履歴」画面を開く。
   - 「パックの開封 -150pt」の行に、有償と無償それぞれから払った額が出る。無償 pt から先に使われる。
   - → [pt の履歴を確認する](./coin-history.md)

## データの持ち方

- `pack`: `type = premium`、`priceCoins = 150`、`genreId` が天体（seed のサンプルのジャンル）。
- `pack_featured_card`: ブラックホールと月の重み 5（登録のないカードは 1）。
- `coin_withdraw`: 開封1回につき1行（`purpose = pack_open`）。
- `coin_deposit_withdraw`: どの獲得分からいくら払ったか。

## 対応するテスト

- `packages/api/src/routers/consumer/pack/open/handler.integration.test.ts`
  - 「有料パックは価格分の pt を消費し、無償 pt から先に使う」
  - 「pt が足りないと開封できず、何も保存されない」
  - 「同時に有料パックを開けても、残高を超えて消費されない」
- `packages/api/src/routers/consumer/pack/get/handler.integration.test.ts`
  - 「有料パックは pt が足りないと開封できない」
