# 手放したカードの開封結果を確認する

> ステータス: 実装済み。iOSシミュレーターとAPIで確認する。実機は未確認。

## ストーリー

カードを集める利用者として、売却後も自分が引いたカードの開封結果を確認したい。現在の所持枚数と過去の開封結果を区別できるとうれしい。

## 動作確認の手順

1. ローカルのiOSアプリでゲスト名を確認し、`bun packages/db/src/seed/ownership-history-cli.ts --user-name ゲスト名` を実行する。
   - 既存データを消さず、5枚の開封と、そのうち1枚を確認相手へ移した状態が作られる。
   - 同じコマンドを再実行してもコピー・履歴・売上は増えない。
2. マイページの開封履歴から「所有権履歴の確認カード」の結果を開く。
   - 売却後も当たった5枚が表示される。
3. カード詳細を開く。
   - 所持枚数は4枚で、開封結果の5枚とは区別される。
   - 過去に取得した種類はすべて手放しても詳細を開ける。未取得の利用者には公開しない。
   - → [コレクションを確認する](./collection.md)
4. 無料パックを開封し、結果を確認する。
   - 開封結果、所持品、初回付与履歴が同時に保存される。
   - 同じ種類が複数出た場合、NEWは初めての1枚だけに付く。売買で獲得済みの種類にNEWは付かない。
   - → [無料パックを開ける](./open-free-pack.md)
5. APIテストで落札の並行実行と売上保存の失敗を再現する。
   - 同じ売買の移転履歴と入金は1件だけになる。
   - 保存が失敗した場合は所有者・履歴・出品状態も取り消され、再試行できる。

## データの持ち方

- `pack_opening` と `pack_opening_card` は、開封1回と当たったカードを保持する。
- `user_card.owner_id` は現在の所有者を保持する。
- `user_card_ownership_transfers` は初回獲得と移転元・移転先を記録する。
  - 初回付与は移転元がnull。売却後も履歴は残す。
  - 旧獲得記録で相手や個体を特定できない場合は、不明な列をnullにする。適用済みマイグレーションの `legacy_acquisition` は独立コマンドで `pack_open` に統一する。統一前も閲覧権限は保持する。seedの初回付与は `pack_open` を使う。
