# 閲覧数からカードのレアリティを確認する

> ステータス: 実装済み

## ストーリー

カードを集める利用者として、月間閲覧数とレアリティの対応を知り、目的のカードを探したい。

## 動作確認の手順

1. `bun packages/db/src/seed/collection-sort-cli.ts` を実行し、iOSアプリで `collection-sort@example.com`（パスワード `password1234`）としてコレクションを開く。
   - ゲストで確認する場合は `--user-id <ローカルの利用者ID>` を付け、ログイン中の利用者に確認用カードを追加する。
2. C、UC、R、SR、レジェンドを順に選び、それぞれのカード詳細を開く。
   - Cは99回、UCは100回、Rは1,000回、SRは10,000回、レジェンドは100,000回と表示される。
3. コレクションでUCに絞り込む。
   - アンコモンのカードが表示され、CやRの確認用カードは表示されない。

## データの持ち方

- 保存した月間閲覧数から5段階に分類する。Cは100回未満、UCは100回以上・1,000回未満、Rは1,000回以上・1万回未満、SRは1万回以上・10万回未満、レジェンドは10万回以上。既存カードにも保存済みの閲覧数で同じ基準を適用し、所持品と出品の紐づけは維持する。

## 対応するテスト

- 取り込みテストで各下限とその直前の値を検証する。APIテストで既存カードの再分類と所持カードの絞り込みを検証する。
- `tests/ios/card-rarity.yaml` で5段階の表示と月間閲覧数を確認する。
