# 無料パックの枠

> ステータス: 実装済み

## ストーリー

ユーザーとして、登録日から毎日10パックを無料で開けたい。
毎日の枠は貯まらないので、毎日アプリを開く理由になる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `taro@example.com` でログインし、パック選択画面を見る。
   - 「無料パック 残り 10」「今日の分 10/10」と表示される。
   - 登録特典はなく、今日の10パックだけ開けられる。
2. 基本パックを開ける。
   - 「今日の分 9/10」になる。毎日の枠が1つ減る。
3. `shiro@example.com` でログインする。このユーザーは今日の枠を使い切っている。
   - パック選択画面に「次の無料パックまで 00:00:00」の形で、日本時間の 0 時までの残り時間が出る。
4. 一覧で基本パックを中央に表示する。
   - パックは押せず、開封画面には移動しない。
5. 一覧で天体パック（有料）を中央に表示する。
   - pt が足りないのでパックは押せない。「pt を購入する」リンクからポイント購入へ進む。
   - → [pt を購入する](./buy-coins.md)

## データの持ち方

- `free_pack_allowance`: ユーザー1人につき1行。最初に無料パックを開けたときに作る。
  - `initialRemaining`: 廃止した登録特典の旧残高。互換性のため保持するが、無料枠には算入しない。新規作成時は 0。
  - `dailyUsedDate` と `dailyUsedCount`: 毎日の枠を最後に使った日（日本時間）と、その日に使った数。
  - 日付が今日でなければ、その日の枠は 10 残っているとみなす。3日開けなくても 30 にはならない。
- 枠を減らすときは「その日の数が 10 未満」を条件にした UPDATE を1文で実行する。同時に開封されても枠を超えない。
