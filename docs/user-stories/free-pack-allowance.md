# 無料パックの枠

> ステータス: 実装済み

## ストーリー

ユーザーとして、登録したときに無料パックをまとめて開け、そのあとも毎日決まった数だけ無料で開けたい。
毎日の枠は貯まらないので、毎日アプリを開く理由になる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `taro@example.com` でログインし、パック選択画面を見る。
   - 「無料パック 残り 30」「今日の分 10/10・登録特典 20」と表示される。
   - 登録時の 20 パックと、今日の 10 パックの合計。
2. 基本パックを開ける。
   - 「今日の分 9/10・登録特典 20」になる。毎日の枠から先に使われる。
3. `shiro@example.com` でログインする。このユーザーは登録時の枠も今日の枠も使い切っている。
   - パック選択画面に「次の無料パックまで 00:00:00」の形で、日本時間の 0 時までの残り時間が出る。
4. 基本パックの詳細画面を開く。
   - ボタンが「あと 00:00:00」になり、押せない。
5. 宇宙パック（有料）の詳細画面を開く。
   - pt が足りないので、ボタンが「pt を購入する」になり、ショップへ進む。
   - → [pt を購入する](./buy-coins.md)

## データの持ち方

- `free_pack_allowance`: ユーザー1人につき1行。最初に無料パックを開けたときに作る。
  - `initialRemaining`: 登録時の枠の残り。初期値 20。期限なし。
  - `dailyUsedDate` と `dailyUsedCount`: 毎日の枠を最後に使った日（日本時間）と、その日に使った数。
  - 日付が今日でなければ、その日の枠は 10 残っているとみなす。3日開けなくても 30 にはならない。
- 枠を減らすときは「その日の数が 10 未満」「登録時の枠が 1 以上」を条件にした UPDATE を1文で実行する。同時に開封されても枠を超えない。
