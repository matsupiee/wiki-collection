# 途中でやめた開封の続きを見る

> ステータス: 実装済み

## ストーリー

開封の演出の途中でアプリを閉じてしまったユーザーとして、あとから続きを見たい。
結果は開けた時点で決まっているので、引き直しにならず安心して閉じられる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `hanako@example.com` でログインし、マイページの「開封履歴」を開く。
   - 4件の開封が新しい順に並ぶ。
   - いちばん新しい基本パックは演出を見ていないので、カード名が「？」で隠れ、「続きを見る」リンクが出る。
2. 「続きを見る」を押す。
   - 開封画面に移動し、パックを破るところから演出が始まる。
3. 5枚をめくり終える。
   - 最後の1枚は織田信長（ダブルレア）で、背景が虹色になる。
4. 開封履歴に戻る。
   - その開封のカード名が表示され、リンクが「結果を見る」に変わる。
5. 演出の途中で右上の「スキップ」を押す。
   - 開封結果画面に移動し、その開封は見終えたものとして記録される。

## データの持ち方

- `pack_opening.revealedAt`: 開封結果画面に到達した日時。null の開封は演出を見ていない。
