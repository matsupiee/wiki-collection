# 対戦のルールと遊び方を確認する

> ステータス: 実装済み

## ストーリー

初めて対戦するプレイヤーとして、対戦画面からルールと遊び方を確認し、編成や練習を始めたい。

## 動作確認の手順

1. `bun run db:seed:battle:ux` で確認用データを作り、`battle-ux1@example.com`、パスワード `password1234` でログインする。
2. 対戦画面を開き、ボトムナビのすぐ上の右側にあるクエスチョンアイコンを押す。
   - ヘッダーには「対戦」を表示し、「Wiki Collection」「DAILY BATTLE」「チームと対戦」の見出しは表示しない。
   - アイコンはスクロールしても同じ位置に固定され、ボトムナビに重ならない。
   - 「対戦のルールと遊び方」モーダルが開く。
   - 編成、ダメージと勝敗、属性相性、練習、日次対戦と順位、強化と素材消費を確認できる。
   - スマートフォン幅でも横にはみ出さず、最後までスクロールできる。
3. 閉じるボタンで閉じ、キーボードでも再度開いて Escape で閉じる。
   - アイコンにフォーカスが戻り、チームやカード、ランキングは変更されない。
   - 開いている間、Tab で背景の操作に移動しない。
4. 「ランキング」タブでもアイコンから同じ説明を開く。
   - タブや選択した日付を維持して閉じられる。

## データの持ち方

- 開閉状態はブラウザのメモリだけで保持し、データを保存しない。
- 属性相性は対戦計算と共通の `affinityRules` を使う。
- 確認用データは既存の `packages/db/src/seed/battle-ux-cli.ts` を利用する。

## 対応するテスト

上記手順をブラウザで確認する。全ストーリーの既存回帰テストは `bun run test` で実行する。
