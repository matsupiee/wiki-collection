# 手応えのあるパック開封を楽しむ

> ステータス: 実装済み。iOSシミュレーターで操作確認済み。実機の触覚・性能は未確認。

## ストーリー

コレクターとして、袋を切る手応えとカードが現れる瞬間を楽しみ、出てきたカードを並べて眺め、気になった1枚を選んで読みたい。

## 動作確認の手順

1. ローカル環境で `bun run db:seed:opening` を実行し、iOSアプリで `opening-juice1@example.com` / `password1234` にログインする。
   - 既存のマスターに5段階すべてのレアリティが必要。既存の利用者や抽選結果は削除しない。
2. `wiki-collection://openings/opening-juice-all-rarities` を開く。
   - 黒背景にオレンジ色の上端が光る袋と切り取り線が表示される。
3. 袋の上端を左から途中までなぞって離す。
   - 光の線が指に追従し、離すと元へ戻る。右端だけに触れても開封されない。
4. 左から右までなぞる。
   - 袋が手前に寄り、青白い光が封を横切る。裏面が袋の口からせり上がって大きく迫り、虹の光を背に左右2枚へ分かれる。対応端末では操作に触覚が返る。
5. 左、右の順で表が自動公開されるまで待ち、気になるカードをタップする。
   - 並んだカードから選んだ1枚を拡大できる。同じ組のもう1枚へ移動できる。左上の戻るボタンで同じ組に戻り、「次のカードへ」で続ける。5枚は2枚、2枚、1枚に分かれ、最後の1枚が中央に出る。
   - `wiki-collection://openings/opening-juice-reference` の最初の組では通常カードの青白い光と、レジェンドの燃えるリングを続けて見られる。最後に開封結果で5枚とNEW表示を確認する。
6. 結果から「もう1パック」を選ぶ。
   - 新しい袋から演出が始まる。→ [無料開封](./open-free-pack.md)
7. `wiki-collection://openings/opening-juice-skip` を開き、袋の表示中または開封中にスキップする。
   - 追加の抽選や消費をせず、結果に進む。→ [開封再開](./resume-opening.md)
8. iOSの「視差効果を減らす」を有効にし、`wiki-collection://openings/opening-juice-reduced` を開く。
   - 袋やカードの移動・回転・拡縮、粒子、フラッシュを抑えて同じ結果を確認できる。「タップで開ける」でも進める。

## データの持ち方

- 既存の `pack_opening` と `user_card` の確定済み結果を使う。
  - 演出の進行は画面内だけに持ち、抽選・価格・提供割合・無料枠を変更しない。
- 確認用seedは専用アカウントに固定IDの開封4件を追加する。
  - 再実行でカードを重複付与しない。開封済みフラグを戻さず、直接リンクから演出を再確認できる。

## 対応するテスト

- `tests/ios/opening-juice.yaml`: iOSシミュレーターで固定結果の5枚、タップ開封、スキップを操作する。
- `tests/ios/opening-gesture.yaml`: iPhone 18 Proで部分スワイプの復帰、全スワイプ開封、もう1パックを確認する。
- APIの既存 `pack/open`、`opening/get`、`opening/reveal` の統合テストで確定結果・消費・再開を確認する。
- ジェスチャーの追従と触覚の強さ、最も遅い対応端末での性能は実機で確認する。
