# 手応えのあるパック開封を楽しむ

> ステータス: 実装済み。iOSシミュレーターで操作確認済み。実機の触覚・性能は未確認。

## ストーリー

コレクターとして、袋を切る手応えとカードが現れる瞬間を楽しみ、出てきたカードを並べて眺め、気になった1枚を選んで読みたい。

## 動作確認の手順

1. iOSアプリのマイページでゲスト名を確認し、ローカル環境で `bun packages/db/src/seed/opening-juice-cli.ts ゲスト名` を実行する。
   - 既存のマスターにC・R・SR・レジェンドのカードが必要。既存の利用者や抽選結果は削除しない。
2. seedが出力した末尾 `all-rarities` のリンクをiOSアプリで開く。
   - 青白い背景と床の薄い反射の前に並んだ袋のひとつをタップすると、その袋が手前に寄り、上端に切り取り線が見える。
   - 左右へ続けて素早くドラッグしても勝手に袋を選択しない。ドラッグ後も中央・左右の袋をタップして選べる。
3. 封の中央でタップし、指をわずかにずらして離す。縦方向にもなぞる。
   - いずれも開封されず、同じ袋でやり直せる。
4. 封の中央付近から右へ短く、少し斜めにゆっくりなぞる。同じリンクを開き直し、左へも試す。
   - 上端の帯がちぎれ、中央がわずかにたわんだ袋口からカードが現れる。対応端末では、袋を開けた瞬間に5枚のうち最も高いレアリティに応じて1回振動する。コモンのみなら微細、レアなら弱く、SRなら強く、レジェンドなら最も強く振動する。
   - リンク末尾を `trace` に替えると、画像の寸法が登録されたカードがあれば先頭に表示される。写真の下端が袋の縁に隠れた状態から現れることを確認できる。
   - 実機ではリンク末尾の `all-rarities` を `common`、`rare`、`sr` に替えてそれぞれ開け、4段階の振動を比較できる。
5. 各カードの上辺が水平に揃っていることを確認し、手前の写真を左右にスワイプする。
   - 短くゆっくり動かして離すと手前の写真が元に戻る。大きく動かすか素早く払うと1枚めくれる。タップでも1枚進める。対応端末では、先頭を含めてR以上の写真が新しく手前に出るたびに1回振動する。
   - 「写真の詳細を見る」で現在の写真とすでにめくった写真を拡大できる。閉じると同じ位置から続けられる。
   - 5枚目をスワイプすると、同じ写真が中央に戻ることなく、5枚が並ぶ開封結果に進む。
6. 結果から「もう1パック」を選ぶ。
   - 新しい袋から演出が始まる。→ [無料開封](./open-free-pack.md)
7. seedが出力した末尾 `skip` のリンクを開き、袋の表示中または開封中にスキップする。
   - 追加の抽選や消費をせず、結果に進む。スキップで結果に進むときは、R以上が含まれていれば最も高いレアリティに応じて1回振動する。→ [開封再開](./resume-opening.md)
8. iOSの「視差効果を減らす」を有効にし、seedが出力した末尾 `reduced` のリンクを開く。
   - 袋やカードの移動・回転・拡縮、粒子、フラッシュを抑えて同じ結果を確認できる。

## データの持ち方

- `pack_opening` と `pack_opening_card` の確定済み結果を使う。
  - 演出の進行は画面内だけに持ち、抽選・価格・提供割合・無料枠を変更しない。
- 確認用seedは指定したローカルゲストに利用者別の固定IDで開封8件を追加する。
  - 再実行でカードを重複付与せず、既存の結果・所有者・開封済みフラグを変更しない。直接リンクから演出を再確認できる。

## 対応するテスト

- `tests/ios/opening-carousel.yaml`: 左右への連続ドラッグでは選択されないこと、左右端の袋をタップして選べることを確認する。

- `apps/native/lib/rarity.test.ts`: カードの順序によらず、開封時の振動を決める最高レアリティを5段階それぞれで確認する。
- `tests/ios/opening-juice.yaml`: iOSシミュレーターで固定結果の5枚、なぞって開封する操作、スキップを操作する。
- `tests/ios/opening-gesture.yaml`: iOSアプリで部分スワイプの復帰、短い横なぞりでの開封、もう1パックを確認する。
- `tests/ios/opening-reduced-motion.yaml`: iOSの「視差効果を減らす」を有効にして5枚の公開と結果への移動を確認する。
- APIの既存 `pack/open`、`opening/get`、`opening/reveal` の統合テストで確定結果・消費・再開を確認する。
- ジェスチャーの追従と触覚の強さ、最も遅い対応端末での性能は実機で確認する。
