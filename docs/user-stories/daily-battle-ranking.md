# 毎日の自動対戦とランキングを見る

> ステータス: 実装済み。本番の定期実行はデプロイ後に有効になる。

## ストーリー

プレイヤーとして、作ったチームが毎日自動で対戦し、結果と順位を確認したい。

## 動作確認の手順

1. [対戦用データ](../development/battles.md)を作る。
2. 2人以上の利用者がチームを保存した状態で、ローカルの定期実行を呼ぶ。
   - ログインや画面の閲覧をきっかけにせず、定期実行で集計される。
   - 同じプレイヤーのチーム同士は対戦しない。
3. 対戦画面の「ランキング」を開く。
   - 日本時間の日付と、各チームの順位・名前・プレイヤー名・勝敗・勝点を確認できる。
   - 「対戦時のカード」で当時の並び順と能力値を確認できる。
4. 同じ日の処理を再度呼び、チームの編集や合成も行う。
   - 保存済みの結果は変わらず、二重集計されない。
   - 旧属性を含む結果には旧ルールである旨を表示する。新しい対戦は記事分類に基づく属性を使う。
5. 別の日の処理を呼ぶ。
   - 新しい編成・強化を使い、日付を選ぶと過去の結果も見られる。
   - 未開催の日は「まだ対戦結果がありません」と表示される。

## データの持ち方

- Cloudflare Cron `0 15 * * *` が日本時間0時に `scheduled` を呼ぶ。
- 対戦は他プレイヤーの全チームとの総当たり。
  - 同じ位置のカード同士の「攻撃力 × 弱点倍率 − 相手の防御力」（最低0）を比較する。同値は引き分け。
  - 弱点を突く攻撃力は2倍。3組の勝ち数でチームの勝敗を決める。
  - 勝ち3点、引き分け1点、負け0点。勝点÷（対戦数×3）で順位を決める。同率は同順位。
  - 対戦相手がいない場合は0戦0点。報酬はない。
- `battle_day` は日付が一意。集計時のチームと能力値、順位を保存する。
  - 1回のSELECTでチームと能力値を取得し、完成した結果全体を1回で保存する。途中の結果は公開しない。

## 対応するテスト

`packages/api/src/routers/consumer/battle/*/handler.integration.test.ts` が属性相性、勝敗、同率順位、対戦対象、日本時間の日付境界、同時実行、再実行、結果の保存を確認する。
