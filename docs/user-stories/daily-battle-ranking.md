# 毎日の自動対戦とランキングを見る

> ステータス: 実装済み。本番の定期実行はデプロイ後に有効になる。

## ストーリー

プレイヤーとして、作ったチームが毎日自動で対戦し、結果と順位を確認したい。

## 動作確認の手順

1. [対戦用データ](../development/battles.md)を作る。
2. 2人以上の利用者がチームを保存した状態で、ローカルの定期実行を呼ぶ。
   - ログインや画面の閲覧をきっかけにせず、定期実行で集計される。
   - 同じプレイヤーのチーム同士は対戦しない。
3. 対戦画面の「ランキング」を開く。
   - 勝点率の計算方法・報酬の説明と、自分の参加チームがない旨の説明文は表示しない。
   - 日本時間の日付と、各チームの順位・名前・ポイントの行を確認できる。
   - 順位の数字は名前の左側に表示する。同率は同順位とし、自分だけに絞り込んでも元の順位を表示する。
   - 自分のチームを左端の線で強調し、自分だけに絞り込める。
   - 行を押すと別ページで、その日の順位・プレイヤー名・勝敗・対戦数・勝率・勝点率・ポイントを確認できる。
   - 勝率は勝ち数÷対戦数。対戦数が0なら勝率・勝点率は「—」と表示される。
   - 自分以外のチームも、対戦時のカードの並び順と能力値、相手ごとの番手・属性倍率・双方のダメージ・勝敗を確認できる。
   - 詳細を再読み込みしても同じ日の結果を表示し、「ランキングに戻る」で日付と自分だけの絞り込みを保持する。
   - 存在しない日付・チームの詳細では記録がない旨を表示し、一覧に戻れる。
4. 同じ日の処理を再度呼び、チームの編集や合成も行う。
   - 保存済みの結果は変わらず、二重集計されない。
   - 旧属性を含む結果も当時のルールで表示し、新しい対戦は記事分類に基づく属性を使う。旧ルールの案内文は表示しない。
5. 別の日の処理を呼ぶ。
   - 新しい編成・強化を使い、日付を選ぶと過去の結果も見られる。
   - 未開催の日は「この日の対戦記録はありません」と表示され、最新結果に戻れる。

## データの持ち方

- Cloudflare Cron `0 15 * * *` が日本時間0時に `scheduled` を呼ぶ。
- 対戦は他プレイヤーの全チームとの総当たり。
  - 同じ位置のカード同士の「攻撃力 × 弱点倍率 − 相手の防御力」（最低0）を比較する。同値は引き分け。
  - 弱点を突く攻撃力は2倍。3組の勝ち数でチームの勝敗を決める。
  - 勝ち3点、引き分け1点、負け0点。勝点÷（対戦数×3）で順位を決める。同率は同順位。
  - 対戦相手がいない場合は0戦0点。報酬はない。
- `battle_day` は日付が一意。集計時のチームと能力値、順位を保存する。
  - 1回のSELECTでチームと能力値を取得し、完成した結果全体を1回で保存する。途中の結果は公開しない。
