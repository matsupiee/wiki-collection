# 旧バージョンからアプリを更新する

> ステータス: 実装済み

## ストーリー

利用者として、手元のアプリがサポート対象外になったときに、ゲームを始める前に更新先を知りたい。

## 動作確認の手順

1. ローカルで `bun packages/db/src/seed/app-update-cli.ts ios 9.0.0` を実行し、バージョン1.0.0のiOSアプリを起動する。
   - ログイン状態にかかわらず「アップデートが必要です」と表示される。パックへのリンクを開いてもゲームを操作できない。
2. 「App Storeを開く」を押す。
   - 配信中の端末ではWiki Collectionのストアページが開く。AndroidではGoogle Playを開く。
3. アプリを背景に移し、最低バージョンを `ios 1.0.0` に変更してからアプリに戻る。
   - バージョンを再確認し、同じ版または新しい版は通常どおり利用できる。
4. APIに接続できない状態でアプリを起動する。
   - 確認失敗の案内が出る。接続を戻して「再試行」を押すと、判定結果に応じた画面に進む。
5. `bun packages/db/src/seed/app-update-cli.ts ios off` でローカル設定を解除する。

## データの持ち方

- D1の `app_update_policy` はOSごとに最低バージョンを1件持つ。行がないOSには更新を要求しない。
- 利用者のログイン状態や個別の端末情報は保存しない。

## 対応するテスト

- `packages/api/src/routers/app-update.integration.test.ts` で未設定、OSの分離、バージョンの境界値を確認する。
- 手順1の設定後に `maestro test tests/ios/force-update.yaml` でiOSアプリの起動とディープリンクを確認する。
