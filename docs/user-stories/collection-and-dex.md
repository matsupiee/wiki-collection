# 集めたカードと図鑑を見る

> ステータス: 実装済み

## ストーリー

カードを集めているユーザーとして、持っているカードを一覧で見て、図鑑でどこまで集まったかを知りたい。
埋まっていない枠が見えると、次に何を集めるかの目標になる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `hanako@example.com` でログインし、コレクション画面を開く。
   - 同じカードは1つにまとまり、所持数が「×2」のように出る。
   - 出品中のカードは「出品中1」と出る。
   - レアリティの高い順に並ぶ。
2. 「レア」で絞り込む。
   - レアのカードだけが出る。
3. 図鑑タブを開く。
   - 「コンプリート 手に入れた数 / 全カード数」が出る。
   - ジャンルごとの集まり具合がバーで出る。ジャンルは Wikidata の分類（seed では 26 個のサンプル）。
   - ジャンルはカードの多い順に並び、最初は 9 個だけが出る。
   - 手に入れたことのないカードは「?」のシルエットで出る。
4. 「すべてのジャンルを見る（26）」を押す。
   - 残りのジャンルも出て、ボタンが「ジャンルをたたむ」に変わる。
5. 10 個目以降のジャンル（例: 川）を押し、「ジャンルをたたむ」を押す。
   - そのジャンルのカードだけが出る。
   - たたんでも、選んでいるジャンルは出たまま残る。
6. 手に入れたカードを押す。
   - カード詳細画面に、要約、ジャンル、月間閲覧数、「Wikipedia で読む」リンク、出典とライセンス表記（CC BY-SA 4.0）が出る。
   - Wikipedia から取り込んだカードは、出典の行に「取り込んだ時点の版」のリンクも出る。seed のサンプルカードには出ない。
   - → [Wikipedia の記事をカードとして取り込む](./import-cards-from-wikipedia.md)
   - カードはマウスや指の位置に合わせて傾き、レア以上はホログラムが動く。
7. 手に入れたことのないカードの詳細画面を URL で直接開く。
   - 「まだ手に入れていないカードです」と出て、中身は見られない。

## データの持ち方

- `user_card`: 1枚ごとの所持。`status` が `owned`（所持中）と `listed`（出品中）のものを数える。
- `card_discovery`: 一度でも手に入れたカード。還元や売却で手放しても消えないので、図鑑は減らない。
