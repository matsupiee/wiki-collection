# 3枚のカードでチームを作る

> ステータス: 実装済み

## ストーリー

プレイヤーとして、所持カードから3枚を選び、最大3つのチームで対戦に参加したい。

## 動作確認の手順

1. [対戦用データ](../development/battles.md)を作り、対戦画面を開く。
   - 参加予定数・次回開催時刻・自動参加の説明・自分の結果へのショートカット・「3枚で挑む、毎日の自動対戦。」・「能力値と対戦ルール」は表示しない。
2. 一覧の「＋ チームを編成」を押し、シートで名前と異なる所持カード3枚を選んで保存する。
   - 空き枠が自動で選ばれ、既存チームは上書きされない。
   - 画像付き3列の一覧でカードを押すたびに選択し、上部に選択順で表示する。番手を先に指定する操作はない。
   - 選択済みをもう一度押すか上部のカードを押すと解除する。3枚選択中は未選択カードを選べず、解除してから入れ替える。
   - 選択したカードはスクロール中も上部に残り、左右の矢印で順番を交換できる。
   - 上部のカード画像は一覧と同じ正方形で表示し、未選択の枠も同じ縦横比になる。スマートフォン幅でもPC幅でも横長につぶれない。
   - 検索・フィルター・自動編成・練習対戦は編成シートに表示しない。
   - 並び順を保持してチームが表示される。同じ種類のカードでも所持品が別の1枚なら編成できる。
   - 各カードの右側にカードの輪郭と上向き矢印を組み合わせたアイコンの強化ボタンが横並びで表示され、「カード詳細」ボタンは表示されない。スマートフォン幅でも横にはみ出さない。
   - 矢印ボタンには読み上げ用の「カード名を強化」と、ホバー時の「強化」の案内があり、押すとそのカードを選択した強化シートが開く。
   - カード画像とカード名をそれぞれ押すと、そのカードの詳細ページへ移動できる。強化ボタンを押した場合は詳細へ移動せず、強化シートが開く。
3. チーム3を保存する。
   - 保存先は1〜3だけ。他のチームで使っているカードも選べる。
4. チーム2の「編集」を押し、シートで並びと名前を変えて保存する。
   - 保存済みの値が最初から表示される。未保存の変更がある状態で閉じると、破棄か編集継続を選べる。
   - チーム数が増えず、同じ枠が更新される。
5. 編成中のカードを出品・合成素材として使おうとする。
   - 操作できない。ベースカードとしての合成はできる。
6. チームを解除し、確認シートで確定する。
   - 他のチームでも使われていなければ、カードの出品・素材利用が可能になる。

## データの持ち方

- `battle_team` に利用者、1〜3の枠、名前、順序付きの所持カード3枚を保存する。
  - 利用者と枠が一意。3枚の所持品IDは重複できない。
  - 保存時点の所有権・状態・能力値をDB内で検証する。
  - 消費や出品も同じDB文内で編成の有無を検証する。

## 対応するテスト

`packages/api/src/routers/consumer/battle/*/handler.integration.test.ts` が枠・枚数・所有権・未計測・更新・解除・消費保護を確認する。

`apps/native/lib/battle-selection.test.ts` が選択順・3枚上限・解除後の追加を確認する。
