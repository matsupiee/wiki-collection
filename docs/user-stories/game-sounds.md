# 効果音でゲームの操作を確認する

> ステータス: 実装済み。

## ストーリー

コレクターとして、パックの切り替えや開封、タブやカードの選択が受け付けられた瞬間を音でも知りたい。

## 動作確認の手順

1. `bun packages/db/src/seed/opening-juice-cli.ts` で確認用データを作り、iOSアプリで `opening-juice1@example.com` / `password1234` にログインする。消音モードを解除し、音量を上げる。
2. パック一覧で横にスワイプする。
   - 選んだパックが切り替わると、袋を横に払うような短い「シュッ」という音が1回鳴る。同じパックに戻る短いドラッグでは鳴らない。
3. ボトムタブの「コレクション」をタップし、所持カードを選ぶ。
   - タブを押したときとカード詳細を開くときで音が異なる。
4. パックタブで無料パックを開封し、袋を選んで、上端の封を端から端までなぞる。
   - 袋を開ける瞬間に上昇するチャイムが鳴る。カードをめくると短いカード選択音が鳴る。
5. iOSの消音モードを有効にしてタブを切り替える。
   - 音は鳴らず、選択したタブを開ける。

## データの持ち方

- 効果音はアプリに同梱する。確認用の所持カードは `packages/db/src/seed/opening-juice-cli.ts` で作成する。

## 対応するテスト

- `tests/ios/game-sounds.yaml` でパック切り替え、タブ選択、開封とカード操作を確認する。音の違いと消音は上記の手順で確認する。
