# マイページのメニューから目的の画面を開く

> ステータス: 実装済み

## ストーリー

利用者として、マイページのメニューを用途ごとのまとまりで見て、目的の項目をすぐに見つけたい。

## 動作確認の手順

1. マイページを開く。
   - クエスト、出品・入札の管理、ptの履歴、開封履歴が順に同じ枠に表示される。
2. その下のメニューを確認する。
   - 言語切り替えが独立した枠で表示される。
   - お問い合わせ、利用規約、プライバシーポリシー、特定商取引法に基づく表記、資金決済法に基づく表示が順に別の枠に表示される。
   - 3つの枠は余白で区切られ、追加の見出しは表示されない。
3. 各メニューを押す。
   - 対応する画面が開き、戻る操作でマイページへ戻れる。
   - 規約と法定表記は従来どおりアプリ内ブラウザで開く。
4. ヘッダーのベルを押す。
   - 通知一覧が開く。メニューに重複する通知項目は表示されない。

## データの持ち方

- メニューの分類に新しいデータは保存しない。
- 確認用の利用者・カードは既存の `bun packages/db/src/seed/native-cli.ts` を共用する。
- 表示の整理のみで購入条件や個人情報の取り扱いは変わらないため、規約類の本文変更は不要。

## 対応するテスト

- `tests/ios/profile-menu.yaml`: メニューの表示、各アプリ内画面への遷移、ヘッダーからの通知確認。
- `bun run test`: 全ストーリーに関わる既存の自動テスト。
