# ページに必要なヘッダー操作を表示する

> ステータス: 実装済み

## ストーリー

利用者として、ページで必要な残高やアイコンだけを見て、目的の操作に迷わず進みたい。

## 動作確認の手順

1. パック画面を開く。
   - プレゼントボックス、無料残数、ポイント残高、通知が表示される。
   - プレゼントを押すと無料枠の回復説明が表示される。
2. ポイント購入に進み、戻ってマーケットと商品詳細を開く。
   - ポイントと通知が表示され、プレゼントは表示されない。
3. コレクション、カード詳細、ランキング、マイページを開く。
   - 通知が表示され、プレゼントとポイントは表示されない。
4. マイページのクエスト、お問い合わせ、通知、取引管理、ポイント履歴、開封履歴、言語設定を開く。
   - ヘッダーの3項目は表示されない。
   - 規約ページは従来どおりアプリ内ブラウザで開く。
5. パックに戻る。
   - プレゼント、ポイント、通知が再表示される。

## データの持ち方

- 残高、無料枠、未読状態は既存APIを使う。表示しない項目の取得を止める。
- 確認用データは既存の `bun packages/db/src/seed/native-cli.ts` で作成する。商品詳細の確認には、その確認アカウントの所持カードをマーケットに出品しておく。
- データ構造、購入条件、個人情報の取り扱いは変わらないため、利用規約、プライバシーポリシー、特定商取引法表記の変更は不要。

## 対応するテスト

- `tests/ios/header-visibility.yaml`: iOSアプリの表示条件とパックへ戻った後の再表示。
- `tests/ios/liquid-glass-tabs.yaml`: パックからポイント購入に進み、戻った後もタブを操作できる。
- `bun run test`: 全ストーリーに関わる既存の自動テスト。
