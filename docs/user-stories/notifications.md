# 自分宛ての通知を読む

> ステータス: 実装済み

## ストーリー

利用者として、自分宛てのお知らせを確認し、どこまで読んだか分かるようにしたい。

## 動作確認の手順

1. `bun packages/db/src/seed/notifications-cli.ts` を実行し、iOSアプリに `shiro@example.com` でログインする。初期パスワードは `password1234`。
2. ヘッダーにあるベルに赤い点が付いていることを確認し、ベルをタップする。
   - 通知一覧を開いただけでは赤い点は消えない。
   - 自分宛ての通知が新しい順に並び、「コレクションへようこそ」は未読である。
3. 「コレクションへようこそ」をタップする。
   - 本文が表示され、この通知が既読になる。ほかに未読があれば赤い点が残り、すべて既読になると消える。
4. マイページのヘッダーのベルから一覧を開き直す。
   - 既読の表示が維持される。
5. 通知を配信していないアカウントでログインし直して「通知」を開く。
   - 「通知はありません」と表示される。

## データの持ち方

- `notification` にタイトル、本文、作成日時を保存する。
- `notification_user` に通知と配信先ユーザーの組み合わせを一意に保存する。
  - `isRead` は初期値が false で、同じ通知でも利用者ごとに独立する。

## 対応するテスト

- `packages/api/src/routers/consumer/notification/` の統合テストで宛先、順序、認証、既読更新を確認する。
- `tests/ios/notifications.yaml` で本文の表示と再訪時の既読状態を確認する。
