# 編成を練習対戦で試す

> ステータス: 実装済み

## ストーリー

プレイヤーとして、保存したチームを試し、相性と勝敗の理由を理解して次の編成に役立てたい。

## 動作確認の手順

1. `bun run db:seed:battle:ux` を実行し、`battle-ux1@example.com`、パスワード `password1234` でログインする。
2. チーム一覧の「練習対戦」を押す。
   - 編成・編集とは別のシートで開く。保存済みのチームを使い、カード選択は行わない。
3. 練習用サンプルを選び、「このチームで試す」を押す。
   - 3番手それぞれの双方の攻撃・相性倍率・相手の防御・ダメージ・勝敗を表示する。
   - カード・ptを消費せず、チームの保存やランキング更新は行わない。
4. シートを閉じ、チームの「編集」で並びを変えて保存し、もう一度「練習対戦」を開く。
   - 保存した新しい並び順で計算する。相手を変更すると、直前の結果は消える。
5. 最新結果に現行属性の他プレイヤーがいる場合、そのチームを選ぶ。
   - 相手の結果の日付を表示し、その時点の能力値を使う。旧属性・5属性時代のチームや自分のチームは候補にならない。
6. 練習シートを閉じる。
   - 保存済みの編成と日次結果は変わらない。

## データの持ち方

- 保存済み編成を取得し、練習結果はブラウザのメモリだけに保持する。
- 現行対戦と共通の `duelDetails` と `fight` を用いる。
  - 日次結果の内訳には保存されたカードと旧属性の相性を使う。

## 対応するテスト

`packages/api/src/shared/battle/battle-details.test.ts` が現行・旧属性の相性、最低ダメージ、番手交換、内訳と日次集計の一致を確認する。ブラウザでの確認手順は [対戦の開発と確認](../development/battles.md) を参照。
