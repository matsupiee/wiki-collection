# エラー時に利用者向けの案内を読む

> ステータス: 実装済み

## ストーリー

パックを開けなかったとき、何が起きたかと次にできることを画面で知りたい。

## 動作確認の手順

1. `bun packages/db/src/seed/pack-error-cli.ts` でテスト用のパックと開封失敗の応答を用意する。
2. iOSシミュレーターで、APIの接続先を `http://localhost:43871` にしたアプリを起動する。
3. 基本パックの「無料で開封する」を押す。
   - 時間をおいて再試行する案内が表示される。
   - SQL文、テーブル名、スタックトレースは表示されない。

## データの持ち方

- 確認用サーバーが固定のデータをメモリから返す。
