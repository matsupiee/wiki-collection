# 所持カードの総合資産ランキングを見る

> ステータス: 実装済み

## ストーリー

カードを集める利用者として、コレクション全体の価値をほかの利用者と競い、自分の順位を知りたい。

## 動作確認の手順

1. `bun run db:seed:asset-ranking` を実行し、iOSアプリで `asset-ranking2@example.com` にパスワード `password1234` でログインする。
2. コレクションの「総合資産ランキング」を開く。
   - 新しく作った確認アカウントには337点のカードが2枚あり、あなたのカード資産は674点になる。
   - 上位50人を合計点順に表示する。同点は同順位とし、50人の範囲外でも自分の順位を確認できる。
3. 1枚を出品してランキングを開き直す。
   - 出品中も合計は674点。売れた後は337点になる。
4. カードを持たないアカウントでランキングを開く。
   - 自分は未参加と表示され、ほかの利用者の順位を確認できる。

## データの持ち方

- カード1枚の点数は `round(170.2 × log₂(1 + 月間閲覧数 / 60) + 29.8 × log₂(1 + 記事バイト数 / 5259))`。長さが未計測の場合は閲覧数の分だけ加算する。
- 現在の持ち主ごとに所持・出品中のコピーを集計する。合成済みの素材、強化ボーナス、pt残高は含めない。
