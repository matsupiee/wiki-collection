# カードを合成して強化する

> ステータス: 実装済み

## ストーリー

プレイヤーとして、不要な所持カードを素材にして、お気に入りの1枚を強化したい。

## 動作確認の手順

1. [対戦用データ](../development/battles.md)を作り、対戦画面のチーム一覧からカード右側のカードの輪郭と上向き矢印を組み合わせたアイコン（強化）を押す。
   - 強化シートに対象カードが選択された状態で開く。「所持カードを強化」から編成外のカードも選べる。
2. ベースを1枚選び、素材の種類と枚数を選ぶ。
   - 同じ所持品・他人のカード・出品中・消費済み・未計測のカードは選べない。
   - 選択欄はコレクションと同様に画像付き3列で表示し、検索・属性フィルター・並び順の操作は置かない。
   - 編成中・強化対象自身・未計測のカードは素材一覧に表示しない。素材がない場合は空の状態を案内する。
   - 同種の未強化カードは1枠にまとめ、所持枚数と素材に使える枚数を表示する。＋／−または数値入力で必要枚数を選ぶ。
   - 別の種類も続けて選択できる。「未強化をまとめて選択」は強化済みを含めない。合計上限は50枚。
   - 強化後の能力値の目安と計算式の説明は表示しない。
3. 確認画面で画像・能力値・強化済み量を確認し、「N枚を消費して強化」を押す。
   - 個体IDは表示せず、同名カードは能力値と「強化済み」で区別する。強化済みは別枠で明示的に選ぶ。内部では選んだ枚数分の個体を保持する。確定前に素材選択へ戻れる。
   - 処理中は閉じる・再送・選択変更ができない。失敗時はシート内にエラーを表示する。
   - 選択した素材だけが指定枚数なくなり、ベースの攻撃・防御が増える。ptは消費しない。
   - 加算値と強化後の能力値が表示される。小数も蓄積する。
   - レアリティと属性は変わらない。
4. リロードする。
   - 強化値と素材の消費状態が保持される。消費済み素材を再使用できない。
5. 強化したカードをチームから外し、マーケットで売買する。
   - 強化値は購入者に引き継がれる。

## データの持ち方

- `user_card.attack_bonus` と `defense_bonus` に1枚ごとの強化値を保持する。
- 加算式は「素材の現在の能力値 × 0.01 × 係数」。攻撃・防御を個別に計算し、同一の係数を使う。
  - 係数は素材1枚ごとにサーバーで一様に0.2〜1から決め、加算値を合計する。
- 素材は `status = fused` にする。`card_fusion` に素材・ベース・係数・加算値を記録する。
  - 1素材に1記録の一意制約とD1のbatchで、全素材の検証・履歴・素材消費・強化を一括確定する。1枚でも無効なら全件ロールバックする。

## 対応するテスト

`packages/api/src/routers/consumer/battle/*/handler.integration.test.ts` が計算式の上下限、入力・所有権、同時合成、素材の再使用防止、売買による引継ぎを確認する。
