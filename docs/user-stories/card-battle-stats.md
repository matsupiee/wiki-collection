# カードの能力値と弱点を見る

> ステータス: 実装済み

## ストーリー

プレイヤーとして、カードの攻撃力・防御力・属性・弱点を確認してチームを選びたい。

## 動作確認の手順

1. `bun run db:seed:stats` を実行し、`stat-icons1@example.com` / `password1234` でログインする。
2. コレクションからカード詳細を開く。
   - コレクションの各カード、詳細の強化値一覧、出品・還元対象の選択肢も剣・盾と数値で表示され、能力名の文字ラベルは見えない。選択肢は標準のセレクトで表示できる剣・盾の記号を使う。
   - 基本攻撃力が月間閲覧数、基本防御力が記事ソースのバイト数として表示される。
   - 攻撃はオレンジの剣、防御は青い盾のアイコンと数値で表示される。どのページでも2つの能力値は改行せず1行に並ぶ。コレクションでは3列の幅に合わせて小さく表示する。カード詳細では数値を大きく表示し、区切りの「/」は表示しない。画面上に攻撃・防御の文字は出さず、スクリーンリーダーには数値の前に「攻撃」「防御」を伝える。未計測の防御は「未計測」のまま表示する。
   - 属性アイコンと名前が表示され、押すと弱点を確認できる。人物の記事は「人物」、プログラミング言語は「文化」、映画は「文化」、国は「社会」、生物は「自然」となる。
3. 対戦画面を開く。
   - 編成・合成・練習対戦・日次結果・ルール説明・属性相性の説明でも剣と盾を使う。合成完了後の増加値も同じ表示になる。
   - 同じ所持カードの能力値には、その1枚に加算された強化値が含まれる。
   - → [カード合成](./fuse-cards.md)
4. 出品されたカードの詳細を開く。
   - 購入対象の1枚の強化を含めた能力値を確認できる。

## データの持ち方

- `card.monthly_pageviews` が基本攻撃力、`card.article_length` が基本防御力。
  - 記事ソースのバイト数は MediaWiki API から取得する。要約の長さは使わない。
  - 既存の未計測データは `wiki:lengths` と `wiki:load` で補完する。未計測時は「未計測」と表示し、編成・合成対象にはしない。
- 属性は `genre.slug` のWikidata分類IDから共有の対応表で決める。記事IDやタイトルでは決めない。
  - 人物・自然・社会・文化の4属性。未知の分類は総合で、相性倍率はない。
  - 人物 → 文化 → 社会 → 自然 → 人物の順に弱点を突く。属性アイコンを押した相性モーダルで各相性の説明を読める。
  - コレクション、詳細、所持品選択、マーケット、日次対戦で同じ判定を使う。
  - 実在の人物や記事内容の評価を表すものではない。
