# 集めたカードを見る

> ステータス: 実装済み

## ストーリー

カードを集めているユーザーとして、持っているカードと出品中のカードを一覧で確認し、詳細を読みたい。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `hanako@example.com` でログインし、コレクション画面を開く。
   - PC ではヘッダーとボトムタブの白背景が画面幅いっぱいに広がり、中身と本文の幅は最大 28rem のままになる。スマートフォンでも横スクロールは出ない。
   - ヘッダーとレアリティの絞り込みの間には最低 16px の余白がある。
   - ボトムタブの「コレクション」だけが青い文字・アイコンと薄い青の背景になる。
   - 画像は四隅が丸い正方形で表示され、枠やホログラムは重ならない。画像の下にタイトルとジャンルが出る。
   - 画像がない場合や読み込めない場合は、ジャンルの色を背景にタイトルの先頭文字が出る。
   - 同じカードは1つにまとまり、所持数が「×2」のように出る。
   - 出品中のカードは「出品中1」と出る。
   - レアリティの高い順に並ぶ。
   - 一覧の末尾でもボトムタブが画面下端に表示され、最後のカードが隠れない。
   - タブ切り替えやコンプリート率、未所持カードの一覧は表示されない。
2. 「レア」で絞り込む。
   - レアのカードだけが出る。
3. 手に入れたカードを押す。
   - カード詳細画面に、要約、ジャンル、月間閲覧数、「Wikipedia で読む」リンク、出典とライセンス表記（CC BY-SA 4.0）が出る。
   - Wikipedia から取り込んだカードは、出典の行に「取り込んだ時点の版」のリンクも出る。seed のサンプルカードには出ない。
   - → [Wikipedia の記事をカードとして取り込む](./import-cards-from-wikipedia.md)
   - 詳細画面でも画像は角丸の正方形で表示される。
4. 手に入れたことのないカードの詳細画面を URL で直接開く。
   - 「まだ手に入れていないカードです」と出て、中身は見られない。

## データの持ち方

- `user_card`: 1枚ごとの所持。`status` が `owned`（所持中）と `listed`（出品中）のものを数える。
- `card_discovery`: 一度でも手に入れたカード。NEW 判定とカード詳細の閲覧可否の判定に使い、還元や売却で手放しても消さない。
