# Appleでゲーム履歴を引き継ぐ

> ステータス: iOS向けに実装。Apple Accountを使った端末間の確認は別途必要。

## ストーリー

利用者として、登録なしですぐ遊び始め、集めたカードを再インストール後も使いたい。

## 動作確認の手順

1. 初回起動でパック画面を開き、マイページのゲスト名を控える。
   - ローカルでは `bun packages/db/src/seed/guest-history-cli.ts ゲスト名` でカード1枚と2,000ptを追加できる。
2. アプリを終了して再起動する。
   - ゲスト名、カード、残高が変わらない。
3. 未連携のままアプリを削除して再インストールする。
   - 新規ゲストとして始まる。
4. 新しいゲストでカードを集め、マイページの「Appleと連携する」を選ぶ。
   - キャンセルするとゲストのまま、成功すると同じゲスト名で連携済みになる。
5. アプリを削除して再インストールし、「Appleで引き継ぐ」で同じApple Accountを選ぶ。
   - 連携時のカード、ポイント、取引履歴を確認できる。別のApple Accountでは復元できない。

## データの持ち方

- ゲーム履歴はユーザーID単位で保存する。Apple連携時にAppleの識別子を一意に紐付ける。
- 端末のインストールごとに認証用の秘密を生成する。D1にはそのダイジェストを保存する。
