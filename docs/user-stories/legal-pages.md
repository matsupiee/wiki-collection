# 規約類を確認する

> ステータス: 実装済み（運営者名・住所・連絡先などは［］の仮置き。公開前に埋めて法務確認を受ける）

## ストーリー

これから使う人、pt を買おうとしている人として、利用規約や支払いに関する表示を確認したい。
排出率や払い戻しの扱いが分かっていれば、安心して課金できる。

## 動作確認の手順

`bun run dev:local` で起動しておく。

1. ログインせずにトップ画面（`/`）を開く。
   - 下に利用規約、プライバシーポリシー、特定商取引法に基づく表記へのリンクがある。
2. 利用規約（`/legal/terms`）を開く。
   - 無料パックの枠（登録時 20、毎日 10、持ち越しなし）、pt の使う順番と払い戻しの扱い、マーケットの手数料と入札の扱い、RMT の禁止、カードのライセンス（CC BY-SA 4.0）が書いてある。
3. プライバシーポリシー（`/legal/privacy`）を開く。
   - 取得する情報、利用目的、マーケットでニックネームがほかの利用者に表示されること、委託先が書いてある。
4. 特定商取引法に基づく表記（`/legal/tokushoho`）を開く。
5. 資金決済法に基づく表示（`/legal/payment-services`）を開く。
   - 有効期間なし、使用の順番、払い戻しの扱い、資金の保全が書いてある。
6. ログインしてマイページを開く。
   - 4つのページへのリンクがある。

## データの持ち方

- 規約類は画面に直接書いている（`apps/web/src/routes/legal/`）。仕様を変えたら、ここに影響がないかを確かめる。

## 対応するテスト

- API を持たないため、API のテストはない。ブラウザでの動作確認で守る。
