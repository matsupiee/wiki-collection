# pt の履歴を確認する

> ステータス: 実装済み

## ストーリー

pt を使っているユーザーとして、いつ、何で pt が増えたり減ったりしたかを確認したい。
有償と無償のどちらから払ったかも分かるので、残高に納得できる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `hanako@example.com` でログインし、マイページの「pt の履歴」を開く。
   - 残高の合計と、有償・無償の内訳が出る。
   - 獲得と消費が新しい順に並ぶ。
   - 獲得には種類（購入、カードの還元、マーケットの売上、入札の返金）と、有償か無償かが出る。
   - 消費には種類（パックの開封、マーケットで購入、オークションに入札）と、有償・無償それぞれから払った額が出る。
2. 履歴の増減を上から足し引きする。
   - 残高の合計と一致する。
3. ヘッダーの残高を見る。
   - 履歴画面の合計と同じ値。

## データの持ち方

- 残高を1つの値として持つテーブルはない。
  - `coin_deposit`: 獲得の記録。1件ごとに有償か無償かを持つ。
  - `coin_withdraw`: 消費の記録。
  - `coin_deposit_withdraw`: 1回の消費を、どの獲得分からいくら払ったかに割り当てる。
  - 残高 = 獲得の合計 − 割り当ての合計。有償・無償の内訳も同じ計算で出せる。
- 割り当ては無償 pt から先に、同じ種類なら古い獲得分から順に行う。
- `coin_withdraw.userSequence` の unique 制約で、同時に消費されても残高がマイナスにならない。
