# マイページタブを再度押してメニュー一覧へ戻る

> ステータス: 実装済み

## ストーリー

利用者として、マイページ内の画面を開いているときに、選択中のマイページタブをもう一度押してメニュー一覧へ戻り、別の項目を選びたい。

## 動作確認の手順

1. iOSアプリでマイページを開き、クエストを押す。
   - クエスト画面でもマイページタブが選択されている。
2. マイページタブをもう一度押す。
   - メニュー一覧へ戻り、戻るボタンは表示されない。
3. 出品・入札の管理、ptの履歴、開封履歴、言語切り替え、お問い合わせ、ヘッダーの通知でも同じ操作を行う。
   - それぞれの画面からメニュー一覧へ戻れる。
4. メニュー一覧でマイページタブをもう一度押す。
   - メニュー一覧のままになり、画面が重複しない。
5. 言語切り替えを開いてパックタブへ移り、マイページタブを押す。
   - 開いていた言語切り替え画面へ戻る。
   - マイページタブをさらに一度押すとメニュー一覧へ戻る。
6. `wiki-collection://me/wallet` を開いてマイページタブを押す。
   - 直接リンクで開いた場合もメニュー一覧へ戻れる。

## データの持ち方

- 画面の遷移だけを変更し、保存データは追加・更新しない。
- 確認用データは既存の `bun packages/db/src/seed/native-cli.ts` を共用する。
- 販売条件や個人情報の取り扱いは変わらず、利用規約・プライバシーポリシー・特定商取引法表記の変更は不要。

## 対応するテスト

- `tests/ios/profile-tab-reselect.yaml`: 各画面からの再タップ、一覧での再タップ、別タブからの復帰、直接リンクからの復帰。
- `bun run test`: 全ストーリーに関わる既存の自動テスト。
