# 属性アイコンから相性を確認する

> ステータス: 実装済み

## ストーリー

プレイヤーとして、属性をアイコンで見分け、その場で有利な相手と弱点を確認して、対戦の組み合わせを理解したい。

## 動作確認の手順

1. `bun run db:seed:elements` を実行し、`element-icons1@example.com` / `password1234` でログインする。
   - 既存の記事から各属性の代表カードを選ぶ。必要な属性の記事がDBにない場合は先に取り込む。既存利用者の所持品は変更しない。
2. コレクションの属性アイコンを押す。
   - 人物は人型、文化はパレット、社会は建物、自然は葉で、カード名の左側にアイコンだけが表示される。ジャンル名（ヒト、企業集団など）と属性名のテキストはカード情報には表示されない。
   - カード詳細へ移動せず「属性の相性」モーダルが開く。
   - 人物 → 文化 → 社会 → 自然 → 人物の4組が円周上のアイコンと時計回りの矢印で表示される。
   - 矢印の先への攻撃力が2倍、それ以外は等倍と説明される。
   - 押した属性について、攻撃が2倍になる相手と受ける攻撃が2倍になる相手が表示される。
3. 閉じるボタンまたはEscapeで閉じる。
   - 開いたアイコンにフォーカスが戻る。開いている間のTab操作はモーダル内に留まる。
4. カード詳細、出品詳細、対戦のチームや内訳からも属性アイコンを押す。
   - 同じ説明を確認できる。練習対戦などのシート内から開いて閉じても、元のシートが残る。
   - → [カードの能力値と弱点を見る](./card-battle-stats.md)
   - → [練習対戦](./practice-battle.md)
5. 総合・旧属性の表示を確認する。
   - 総合には有利・不利がなく、攻撃・受ける攻撃とも等倍と表示される。
   - 版を持たない過去の結果は、科学技術を含む5属性の相性図と当時の内訳を表示する。科学技術が編成に含まれていなくても旧ルールで表示する。
   - 過去の炎・水・草は「旧属性の相性」として当時の相性だけを表示する。
6. 幅390pxと1280pxで確認する。
   - アイコンや説明が横にはみ出さず、モーダルの内容をスクロールして確認できる。

## データの持ち方

- 属性・相性は既存の `packages/db/src/battle.ts` を使う。
  - アイコンの見た目だけを `ElementBadge` で管理し、科学技術だった分類も文化へ割り当てる。
  - 新しい日次結果のチームに `ruleVersion: 2` を保存する。過去の版なし結果は `1` として表示し、再計算・書き換えはしない。

## 対応するテスト

既存の `packages/api/src/routers/consumer/battle/inventory/handler.integration.test.ts` と `packages/api/src/shared/battle/battle-details.test.ts` で相性計算を確認する。画面の確認は上記の手順で行う。全ストーリーの既存回帰テストは `bun run test` で実行する。
