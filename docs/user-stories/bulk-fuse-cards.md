# 複数のカードを枚数指定でまとめて強化素材にする

> ステータス: 実装済み

## ストーリー

プレイヤーとして、同じカード5枚のうち3枚や複数種類のカードをまとめて選び、一度の確認でお気に入りを強化したい。

## 動作確認の手順

1. `bun run db:seed:fusion` を実行し、`fusion-bulk1@example.com`、パスワード `password1234` でログインする。
   - 初回だけ専用利用者を作る。2種類について未強化5枚ずつと、別枠の強化済みカードを用意する。既存利用者は変更しない。
2. 最初のチームの1番手から「強化」を開く。
   - その種類の未強化カードは「所持5枚・素材に使える4枚」と表示される。強化対象自身は使えない。
3. その種類を3枚、別の種類を2枚選ぶ。
   - 合計5枚になる。数値入力と＋／−で調整でき、素材に使える枚数を超えない。
4. 「選択を解除」「未強化をまとめて選択」を試す。
   - 全解除できる。一括選択は未強化だけを最大50枚まで選ぶ。強化済みは別枠のまま選択されない。
5. 3枚と2枚を選び直し、確認画面へ進む。
   - 種類ごとの枚数、合計5枚と取り消せない旨を表示する。選び直しても数量を保持する。
6. 「5枚を消費して強化」を確定し、再読込する。
   - 選んだ5枚だけがなくなり、強化対象に加算値の合計が保存される。未選択・編成中・別枠の強化済みカードは残る。
   - 失敗時は一部の素材だけを消費せず、選択とエラーを表示する。

## データの持ち方

- 画面では未強化カードを `cardId` ごとにまとめ、内部では使用する `user_card.id` を配列で保持する。
- 強化済みは個別の枠で保持する。同名でも記事IDが異なるカードはまとめない。
- `battle.fuse` は1〜50枚の重複しない素材IDを受け取り、素材ごとの履歴と消費、ベースへの合計加算を1つのD1 batchで確定する。
