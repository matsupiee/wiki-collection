# iOS標準のタブで画面を切り替える

> ステータス: 実装済み。Liquid Glassの表示にはiOS 26以降が必要。

## ストーリー

iOSアプリの利用者として、OSに馴染むLiquid Glassのタブで、パック・コレクション・ランキング・マーケット・マイページを切り替えたい。

## 動作確認の手順

1. [開発手順](../development/native-app.md)に従ってAPIとExpoを起動し、`bun packages/db/src/seed/native-cli.ts` を実行して専用利用者でログインする。
2. iOS 26以降で5つのタブを順にタップする。
   - OS標準のLiquid GlassとSF Symbolsで表示し、選択した画面に切り替わる。
   - 同時にカスタムタブは表示されない。
3. コレクションを末尾までスクロールする。
   - 末尾のカードをタブに隠さず操作できる。
4. カード詳細を開き、コレクションへ戻る。パックを開封する。
   - カード詳細でもコレクションが選択されたOS標準タブが表示され、別のタブへ移動できる。
   - 開封演出中はタブを表示せず、開封結果ではパックが選択されたOS標準タブが表示される。
5. Expo WebとAndroidで5つのタブを切り替える。
   - 従来の表示で各画面へ移動できる。
   - 旧iOSではLiquid GlassではなくOS標準の従来のタブを表示する。

## データの持ち方

- タブの表示には新しいデータを保存しない。
- `packages/db/src/seed/native-cli.ts` の確認利用者・カードを共用する。

## 対応するテスト

- `tests/native/app.spec.ts`: ブラウザーでのタブ遷移と既存の主要操作。
- `bun run test`: 全既存ストーリーに対応するAPI・画面ロジックの回帰テスト。
- `tests/ios/liquid-glass-tabs.yaml`: iOSアプリの開封履歴とポイント購入でOS標準タブの表示と画面切り替えを確認する。
