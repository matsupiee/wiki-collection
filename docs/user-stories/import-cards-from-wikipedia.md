# 日本語版 Wikipedia の全記事をカード候補にする

> ステータス: 全記事の候補作成、R2への月別バックアップ、ローカル・本番D1への読み込みを実装済み。

## ストーリー

利用者として、閲覧数が少ない記事もパックから集めたい。

## 動作確認の手順

1. [取り込み手順](../development/wiki-seed.md) に従い記事と閲覧数のダンプを処理する。
   - 閲覧数ダンプに行がない記事も候補に入る。
   - タイトルと要約は記事ダンプの同じ版から保存され、公開時もその版の文章を読める。
2. 対象月を指定して候補をバックアップする。
   - 2026年10月の入力は `wiki-source/ja/2026-10/articles-ja.jsonl` として元ファイルと同じ内容で保存される。
3. ローカルのJSONLを指定して本番D1にカードを一括投入する。
   - 新形式ではWikimediaのメタデータAPIに接続しなくても、保存した分類と帰属情報でカードを作成できる。
   - 分類がない記事や事件・事故、曖昧さ回避、一覧は除外される。
   - 固定の閲覧数基準でレアリティが決まる。
   - 同じ版をもう一度読み込んでもカードと所持品が重複しない。
   - 画像保存コマンドで、R2にあるWebPの寸法を対応するカードに記録できる。
4. ローカルでは開発用500件でiOSアプリの基本パックを開く。
   - → [カード画像を保存して表示する](./store-card-images.md)

## データの持ち方

- R2に対象月別の記事候補を保存する。本番D1のseedはローカルの記事候補JSONLを読む。
- D1は記事IDと言語でカードを識別する。要約の版、画像の出典、レアリティを保持する。

## 対応するテスト

取込パッケージのダンプ・除外・D1読み込みテストと、APIのローカルseed統合テストで確認する。
