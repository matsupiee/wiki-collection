# コレクションを並び替える

> ステータス: 実装済み

## ストーリー

カードを集めているユーザーとして、引いた順・閲覧数順・記事サイズ順でコレクションを並び替え、新しく引いたカードや閲覧数の多いカードを見つけたい。

## 動作確認の手順

`bun run db:seed:collection` で専用ユーザーと4種類のカードを作り、`bun run dev:local` で起動する。seed は既存データを削除せず、再実行してもカードを増やさない。

1. `collection-sort@example.com` / `password1234` でログインしてコレクションを開く。
   - レアリティ列の右端に並び順の選択欄がある。初期値は「引いた順」。
   - 「記事サイズ未計測」「新しいカード」「記事サイズトップ」「閲覧数トップ」の順に表示される。
2. 「閲覧数順」を選ぶ。
   - 「閲覧数トップ」「記事サイズトップ」「新しいカード」「記事サイズ未計測」の順になる。
3. 「記事サイズ順」を選ぶ。
   - 「記事サイズトップ」「新しいカード」「閲覧数トップ」「記事サイズ未計測」の順になる。
   - 未計測の記事サイズは末尾になる。
4. 「レア」で絞り込む。
   - 記事サイズ順を維持したまま「記事サイズトップ」「閲覧数トップ」だけが表示される。
5. 「閲覧数順」に切り替える。
   - レアの絞り込みを維持したまま「閲覧数トップ」「記事サイズトップ」の順になる。
6. 「すべて」「引いた順」に戻す。
   - 最初と同じ順番になる。カードを押すと詳細を開ける。
   - → [集めたカードを見る](./collection.md)
7. 幅 375px の画面で同じ操作をする。
   - 並び順の選択欄は右端に表示され、レアリティ列だけを横スクロールできる。ページ全体は横にはみ出さない。

## データの持ち方

- `user_card.created_at`: 現在所持中・出品中の同種カードの最新日時を引いた順の基準に使う。
- `card.monthly_pageviews` と `card.article_length`: 閲覧数・記事サイズを高い順に並べる。
- 同値の場合は引いた順、日時も同じ場合はカード ID 順にする。並び替えても所持数・出品数は変わらない。
