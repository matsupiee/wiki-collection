# コレクションを並び替える

> ステータス: 実装済み

## ストーリー

カードを集めているユーザーとして、引いた順・攻撃力順・防御力順でコレクションを並び替え、新しく引いたカードや能力値の高いカードを見つけたい。

## 動作確認の手順

`bun run db:seed:collection` で専用ユーザーと4種類のカードを作り、`bun run dev:local` で起動する。seed は既存データを削除せず、再実行してもカードを増やさない。

1. `collection-sort@example.com` / `password1234` でログインしてコレクションを開く。
   - レアリティ列の右端に並び順の選択欄がある。初期値は「引いた順」。
   - 「防御未計測」「新しいカード」「防御トップ」「攻撃トップ」の順に表示される。
2. 「攻撃力順」を選ぶ。
   - 「攻撃トップ」「防御トップ」「新しいカード」「防御未計測」の順になる。
3. 「防御力順」を選ぶ。
   - 「防御トップ」「新しいカード」「攻撃トップ」「防御未計測」の順になる。
   - 未計測の防御力は末尾になる。
4. 「レア」で絞り込む。
   - 防御力順を維持したまま「防御トップ」「攻撃トップ」だけが表示される。
5. 「攻撃力順」に切り替える。
   - レアの絞り込みを維持したまま「攻撃トップ」「防御トップ」の順になる。
6. 「すべて」「引いた順」に戻す。
   - 最初と同じ順番になる。カードを押すと詳細を開ける。
   - → [集めたカードを見る](./collection.md)
7. 幅 375px の画面で同じ操作をする。
   - 並び順の選択欄は右端に表示され、レアリティ列だけを横スクロールできる。ページ全体は横にはみ出さない。

## データの持ち方

- `user_card.created_at`: 現在所持中・出品中の同種カードの最新日時を引いた順の基準に使う。
- `card.monthly_pageviews` と `card.article_length`: 一覧に表示する基本の攻撃力・防御力を高い順に並べる。強化ボーナスは含めない。
- 同値の場合は引いた順、日時も同じ場合はカード ID 順にする。並び替えても所持数・出品数・重複還元数は変わらない。

## 対応するテスト
