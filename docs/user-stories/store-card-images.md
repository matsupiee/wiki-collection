# 開封したカードの画像を表示する

> ステータス: 高レアリティの事前保存とコモン開封時の保存を実装済み。

## ストーリー

利用者として、初めて引いたコモンにも画像が表示され、その後もコレクションで見られるようにしたい。

## 動作確認の手順

1. ローカルseedを実行し、画像付きのR・SR・レジェンドを確認する。
   - 保存済みの画像はR2から配信される。
2. iOSアプリで基本パックを開く。
   - 未保存のコモン画像は保存中もCommonsから表示できる。
3. 保存完了後に同じカードをコレクションで開く。
   - 同じ画像URLからR2のWebPが返る。
   - 再び引いても同じ画像を重複保存しない。

## データの持ち方

- 元のURLとクレジットをカードに保持し、元URLごとにR2オブジェクトを1つ保存する。
- 保存に失敗してもD1に記録した所持品と開封結果は保持する。

## 対応するテスト

APIの開封・画像配信・ローカルseedテスト、および取込パッケージの画像転送テストで確認する。
