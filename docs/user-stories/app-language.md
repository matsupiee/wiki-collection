# アプリの表示言語を切り替える

> ステータス: 日本語と英語の画面表示を実装済み。

## ストーリー

利用者として、集めた記事の言語にかかわらず、自分の読みやすい言語でパックを開けて図鑑を見たい。

## 動作確認の手順

1. `NATIVE_SEED_PREFIX=language bun packages/db/src/seed/native-cli.ts` で確認用利用者を作る。
2. iOSの設定でアプリの言語を英語にし、language1@example.com でログインする。
   - 5つのタブ、パック名、開封ボタンと読み上げラベルが英語で表示される。
3. 基本パックを開封して結果からコレクションへ移動する。
   - 記事タイトルは日本語で、件数や操作は英語で表示される。
4. Profile の Language で「日本語」を選び、同じカードの詳細を開く。
   - 所持品と記事は同じで、操作と読み上げが日本語に切り替わる。
5. 再起動してマイページの「言語切り替え」を開く。
   - 「日本語」が選択されている。「端末の設定に従う」を選ぶと表示が英語に戻る。

## データの持ち方

- 表示言語の選択は端末に保存する。初期値は「端末の設定に従う」。
- UIの辞書はアプリに含める。記事、配信者が書いた通知本文、リンク先の規約本文は元の言語で表示する。

## 対応するテスト

辞書のキーと変数の一致、優先言語の選択、APIのポイント不足理由を自動テストする。英語での開封から記事詳細までの操作は `tests/ios/app-language.yaml` で確認する。マイページでの切り替え、再起動、端末設定への復帰は `tests/native/app.spec.ts` でも確認する。
