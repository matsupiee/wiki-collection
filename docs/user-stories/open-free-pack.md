# 無料パックを開けてカードを手に入れる

> ステータス: 実装済み

## ストーリー

登録したばかりのユーザーとして、無料の基本パックを開けてカードを手に入れたい。
ポケポケのような豪華な開封の演出があると、引くこと自体が楽しくなり、また開けたくなる。

## 動作確認の手順

`bun run db:seed` を実行し、`bun run dev:local` で起動しておく。

1. `taro@example.com`（パスワード `password1234`）でログインする。
   - パック選択画面（`/packs`）に移動する。ヘッダーの下に案内バナーを挟まずパックが表示される。
   - パックは銀色の箔袋で、上下に圧着線、表面に斜めの刻印がある。「WIKI COLLECTION」と本のアイコンが表示される。袋の表面にはパック名が出ず、種類は袋の下の説明で確認できる。
   - 開封画面でも同じ袋のデザインを使う。
   - スマートフォン幅でもページ全体の横スクロールが出ない。切り替えボタンを押すと選んだパックが中央に移り、袋の反射部分が操作を妨げない。
   - 「無料パック 残り 10」「今日の分 10/10」と表示される。
2. パック選択画面の表示を確認する。
   - 排出率・出やすいカードの折りたたみや排出率の表は表示されない。
   - 無料パックでは「パックをタップして開封」の案内文を表示しない。
3. カルーセルの中央の基本パックをタップする。
   - 詳細画面や確認ダイアログを挟まず `/openings/$openingId` に移動する。
   - 処理中に連打しても重複して開封しない。左右のスワイプでは開封しない。
   - 開封画面に移動し、ヘッダーと下のタブが消えて全画面になる。
   - 白い画面のあと、パックが小さい状態から拡大して出てくる。
4. パックの上端の点線を、左から右へなぞる。
   - iOSでは開封演出の画面の「スワイプで戻る」が無効になり、切り口をなぞっても前の画面へ戻らない。途中で離して再度なぞっても開封できる。
   - なぞった所まで白い光の線が伸びる。途中で指を離すと線は戻る。
   - 右端まで届くと、画面が一瞬白く光り、パックの上部が飛んでいく。
   - 「タップで開ける」を押しても破れる。
5. カードの束が出てきたら、画面をタップして1枚ずつめくる。
   - 1枚目はコモン。5枚はレアリティの低い順に並び、いちばん良いカードが最後に来る。
   - 初めて手に入れたカードには NEW バッジが出る。同じパックの2枚目以降の同じカードには出ない。
   - カードの下に、レアリティの数だけ ◇ が1つずつ出る。レジェンドは ☆。
   - 画像は角丸の正方形で、タイトルとジャンルが下に出る。レア以上のカードは周りに光の粒が舞う。ダブルレアは背景が虹色、レジェンドは金色になる。
   - 次のカードがレジェンドのときは、束の縁が金色に光る。
6. 5枚目をめくったあとにもう一度タップする。
   - 開封結果画面に移動し、5枚が3枚と2枚の2段で並ぶ。
7. パック選択画面に戻る。
   - 「無料パック 残り 9」「今日の分 9/10」になる。毎日の枠が1つ減る。
   - → [無料パックの枠](./free-pack-allowance.md)
8. 開封結果に戻り、「もう1パック」を押す。
   - 同じパックの開封画面に移動する。

9. `/packs/basic` に直接アクセスする。
   - 詳細画面は表示されず、開封も行わずに `/packs` に戻る。

## データの持ち方

- `pack_opening`: 開封1回ごとの記録。抽選は一覧のパックをタップした時点でサーバーが行う。
  - 演出は保存済みの結果を見せるだけなので、リロードしても引き直しにならない。
- `user_card`: 出た5枚。`slot` がめくる順番（レアリティの低い順）。`isNewOnAcquire` が NEW バッジ。
- `card_discovery`: 初めて手に入れたカード。NEW の判定に使う。
- `free_pack_allowance`: 無料枠の残り。
