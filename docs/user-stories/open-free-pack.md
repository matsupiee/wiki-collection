# 無料パックを開けてカードを手に入れる

> ステータス: 実装済み

## ストーリー

登録したばかりのユーザーとして、無料の基本パックを開けてカードを手に入れたい。
ポケポケのような豪華な開封の演出があると、引くこと自体が楽しくなり、また開けたくなる。

## 動作確認の手順

`bun packages/db/src/seed/index.ts` を実行し、`bun run dev:local` で起動しておく。

1. `taro@example.com`（パスワード `password1234`）でログインする。
   - パック選択画面（`/packs`）に移動する。ヘッダーと中央の袋の間には約72pxの余白があり、袋の下には反射が見える。
   - 黒い袋にオレンジの斜めの帯と丸い本のマークが見える。種類は袋の下の説明で確認できる。
   - 袋をゆっくり横にドラッグすると指に追従し、左右の袋が連続して入れ替わる。途中で指を戻せる。指を離すと最寄りの袋が中央に収まり、短く速いスワイプでも隣の袋に切り替わる。
   - スマートフォン幅でもページ全体の横スクロールが出ない。切り替えボタンを押すと選んだパックが中央に移り、袋の反射部分が操作を妨げない。
   - ヘッダーのポイントの左にプレゼントボックスのアイコンと「10」と表示される。
2. パック選択画面の表示を確認する。
   - 抽選時の1〜2枠はC80%・UC20%、3〜4枠はC60%・UC30%・R10%、5枠目はC48%・UC30%・R20%・SR1.5%・レジェンド0.5%。演出と結果はレアリティの低い順に並ぶため、表示順は抽選枠の番号とは一致しない。
   - 排出率・出やすいカードの折りたたみや排出率の表は表示されない。
   - 無料パックでは「パックをタップして開封」の案内文を表示しない。
   - 開封ボタンの上に「10分で1パック回復（最大10パック）」などの回復間隔・上限の説明を表示しない。
3. 基本パックをタップしても残り数が変わらないことを確認し、「無料で開封する」を押す。
   - 詳細画面や確認ダイアログを挟まず `/openings/$openingId` に移動する。
   - 処理中に連打しても重複して開封しない。左右のスワイプでは開封しない。
   - 開封画面に移動し、ヘッダーと下のタブが消えて全画面になる。
   - 黒背景に選択画面と同じデザインの袋が横から登場し、中央に収まる。
4. 袋をタップして手前に寄せ、上端の封を中央から右へ短くなぞる。
   - iOSでは開封演出の画面の「スワイプで戻る」が無効になり、切り口をなぞっても前の画面へ戻らない。途中で離して再度なぞっても開封できる。
   - なぞった所まで白い光の線が伸びる。わずかに指を動かして離すと線は戻る。
   - 横に短くなぞると封の帯がちぎれて袋が開く。右から左へなぞっても開けられる。
5. 正方形の写真が重なって表示される。手前から順にタップしてめくる。
   - 画像のないカードでは、タイトルの先頭の1文字が中央に表示され、文字の上端から下端まで見える。
   - 「写真の詳細を見る」で拡大できる。閉じると同じ写真に戻る。初めて手に入れたカードは開封直後の拡大表示と結果でNEWを確認できる。同じカードが複数出た場合は最初の1枚だけに表示する。
   - → [開封演出](./pack-opening-juice.md)
6. 5枚目を確認してめくる。
   - 開封結果画面に移動し、5枚が3枚と2枚の2段で並ぶ。
7. パック選択画面に戻る。
   - ヘッダーのプレゼントボックスの横が「9」になり、カウントダウンは表示されず「無料で開封する」から続けて開封できる。
   - → [無料パックの枠](./free-pack-allowance.md)
8. 開封結果に戻り、「もう1パック」を押す。
   - 同じパックの開封画面に移動する。

9. `/packs/basic` に直接アクセスする。
   - 詳細画面は表示されず、開封も行わずに `/packs` に戻る。

## データの持ち方

- `pack_opening`: 開封1回ごとの記録。抽選は「無料で開封する」を押した時点でサーバーが行う。
  - 演出は保存済みの結果を見せるだけなので、リロードしても引き直しにならない。
- `pack_opening_card`: 出た5枚の種類とカード個体を枠ごとに記録する。
- `user_card`: 現在の所有者を `ownerId` に保持する。
- `user_card_ownership_transfers`: カード個体の初回付与・移転の履歴。過去の獲得があるかをNEW判定に使う。
- `free_pack_allowance`: 無料枠の残り。
