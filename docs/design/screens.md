# 画面設計

> ステータス: 主要な画面はネイティブアプリに実装済み。ゲーム画面は `apps/native/app/`、規約ページだけを `apps/web/src/routes/legal/` に残す。

[requirement.md](../requirement.md) の要件を、スマートフォンの縦画面を基準にしたネイティブアプリ（Expo / React Native）の画面設計。パスはアプリ内の画面を表し、規約ページはアプリ内ブラウザでWebを開く。
PC では本文とヘッダー・ボトムタブの中身を中央の最大 28rem 幅に置き、ヘッダーとボトムタブの白背景は画面幅いっぱいに広げる。本文の左右は背景で埋める。
ヘッダーの下には最低 16px の余白を置く。選択中のボトムタブはアイコンと文字を青くし、薄い青の背景を付ける。検索条件を変えたり配下の画面へ移動したりしても、対応するタブの選択を保つ。

## 全体の構成

画面下のタブで4つの領域を切り替える。タブは本文のコンテナの外で画面下端に固定し、長い一覧をスクロールしても操作できる。本文の末尾にはタブとセーフエリアの高さ分の余白を確保する。開封演出中はタブとこの余白を外す。ヘッダーには常に pt 残高を出し、押すとポイント購入へ進む。

| タブ         | 主な画面                             |
| ------------ | ------------------------------------ |
| パック       | パック選択、パック詳細、開封         |
| コレクション | 所持カード一覧、カード詳細           |
| マーケット   | フリマ、オークション、出品           |
| マイページ   | 取引、残高履歴、開封履歴、規約 |

```mermaid
flowchart LR
  LP[トップ] --> Login[ログイン・登録]
  Login --> Home[パック選択]
  Home --> PackDetail[パック詳細]
  PackDetail -->|これにする| Rip[開封]
  Rip --> Result[開封結果]
  Result -->|もう1パック| Rip
  Result --> Collection[コレクション]
  Collection --> CardDetail[カード詳細]
  CardDetail -->|還元| Redeem[還元の確認]
  CardDetail -->|出品| Sell[出品]
  Sell --> MyListings[出品・入札の管理]
  Market[マーケット] --> Listing[出品詳細]
  Listing -->|購入・入札| MyListings
  PackDetail -->|pt が足りない| Shop[ポイント購入]
  Listing -->|pt が足りない| Shop
```

## パック選択 `/packs`

参考動画の最初の画面にあたる。パックを横に並べ、中央のパックを大きく見せる。

```txt
┌──────────────────────────────┐
│ wiki collection      ◎ 1,240pt│
├──────────────────────────────┤
│                              │
│   ┌──┐  ┌──────┐  ┌──┐       │
│   │歴│  │ 基本 │  │宇│       │
│   │史│  │パック│  │宙│       │
│   │  │  │      │  │  │       │
│   └──┘  │ 無料 │  └──┘       │
│         └──────┘             │
│          ‾‾‾‾‾‾ 床への映り込み │
│                              │
│  無料パック 残り 8          │
│  今日の分 8/10  │
├──────────────────────────────┤
│  パック コレクション 市場 自分  │
└──────────────────────────────┘
```

- 左右にスワイプ、または左右のパックをタップして中央を切り替える。
  - 中央のパックは拡大し、わずかに上下に浮かぶ。左右のパックは小さく暗めにする。
- 中央のパックをタップするとパック詳細へ進む。
- 無料パックの表示は、残りがあれば残りと今日の分を出し、なければ次の日本時間 0 時までの残り時間を出す。
- 背景はパステルのグラデーションにする。中央のパックの下には床への映り込みを出す。

## パック詳細 `/packs/$packSlug`

参考動画の2枚目にあたる。パックを1つだけ大きく出し、開封ボタンを置く。

```txt
┌──────────────────────────────┐
│ ←                    ◎ 1,240pt│
│                              │
│          ┌────────┐          │
│          │ 宇宙   │          │
│          │ パック │          │
│          │        │          │
│          └────────┘          │
│        ( これにする 150pt )  │
│                              │
│  出やすいカード              │
│  [ブラックホール][太陽][月]  │
│                              │
│  排出率を見る ▼              │
│   4枚目 ◇◇ 70% ◇◇◇ 22% ...   │
│   5枚目 ◇◇◇ 70% ◇◇◇◇ 24% ... │
│               ( ↩ もどる )   │
└──────────────────────────────┘
```

- 開封ボタンの表示はパックと残り枠で変わる。
  - 基本パックで無料枠がある:「これにする（無料）」
  - 基本パックで無料枠がない:「あと 06:21:45」（次の日本時間 0 時まで）で押せない
  - ジャンルパック:「これにする 150pt」。pt が足りなければ「pt を購入」に変わり、ポイント購入へ進む
- 有料パックは確認ダイアログ（「150pt を使って開封します」）を挟む。
- 押した時点でサーバーが抽選と支払いを済ませ、開封画面へ進む。
- 排出率は `pack_slot_rate` から枠ごとに計算して表示する。注目カードは `pack_featured_card` から出す。

## 開封 `/openings/$openingId`

ヘッダーとタブを隠し、黒背景に箔袋とカードを映す。抽選は画面へ進む前に確定している。右上の「スキップ」から同じ結果へ進める。

### 袋を開ける

黒とオレンジの袋が横に流れて中央に収まる。中央の袋をタップするか、上端を左から右へなぞる。途中で離すと切り取り線が戻る。開封が決まると袋が手前へ迫り、青白い光が封を横切る。

### 2枚を公開する

袋の口から銀色の裏面が迫り、虹の光とともに縮小して左右へ分かれる。裏面が回転して正面を向き、光が右下から左上へ走って左、右の順で表が現れる。通常カードには白青の粒子、高レアには火炎リングと赤い残光が出る。

2枚は横に並んで静止する。カードをタップすると拡大でき、閉じると元の並びに戻る。「次のカードへ」で次の組を公開する。5枚は保存された順序で2枚、2枚、1枚に分け、最後の1枚を中央に表示する。動きを減らす設定ではそのまま表を表示する。

### 開封結果

```txt
┌──────────────────────────────┐
│           開封結果           │
│ ──────────────────────────── │
│   NEW      NEW      NEW      │
│  ┌───┐   ┌───┐   ┌───┐       │
│  │   │   │   │   │   │       │
│  └───┘   └───┘   └───┘       │
│       NEW      NEW           │
│      ┌───┐   ┌───┐           │
│      │   │   │ ★ │           │
│      └───┘   └───┘           │
│                              │
│ (もう1パック)  (コレクションへ)│
│   重複カードをまとめて還元 ›  │
└──────────────────────────────┘
```

- 5枚を3枚と2枚の2段で並べる。NEW のカードにはバッジを付ける。
- カードをタップするとカード詳細へ進む。
- 「もう1パック」は同じパックで開封を続ける。開けられないときは理由（残り時間、pt 不足）を出す。
- この画面に来た時点で `pack_opening.revealedAt` を記録する。

### 実装の方針

- カードとパックの動きは CSS の 3D transform と Motion（`motion/react`）で作る。カード画像にはホログラムや傾きの効果を付けず、角丸の正方形で表示する。
- 光の粒は SVG の星を Motion で点滅させて描く。
- 破る操作はパック上端の帯に Pointer Events を付けて、左端からの位置で進み具合を出す。端の 90% まで届いたら破れる。指を離すと線は戻る。なぞるのが難しい人のために「タップで開ける」も置く。
- `prefers-reduced-motion` が有効なときは、拡大・回転を省いたフェードだけの演出にする。
- 未実装: 効果音（Web Audio）、パックの3D表現（Three.js、`.claude/skills` の threejs 系スキルに従う）。

## コレクション `/collection`

```txt
┌──────────────────────────────┐
│ コレクション          ◎ 1,240pt│
│ ジャンル▼ レアリティ▼ 並び順▼│
│ ┌───┐ ┌───┐ ┌───┐ ┌───┐      │
│ │   │ │   │ │   │ │   │      │
│ └───┘ └───┘ └───┘ └───┘      │
│  ×3    ×1    ×2  出品中1     │
│ ┌───┐ ┌───┐ ┌───┐ ┌───┐      │
│ ...                          │
│ [重複をまとめて還元]          │
└──────────────────────────────┘
```

- 所持カード一覧は、同じカードを1つにまとめて枚数を出す。出品中の枚数も出す。
- 「重複をまとめて還元」は、各カードを1枚ずつ残して残りを還元する。対象と受け取る pt を確認ダイアログで出す。

## カード詳細 `/cards/$cardId`

```txt
┌──────────────────────────────┐
│ ←                    ◎ 1,240pt│
│      ┌──────────────┐        │
│      │  (カード拡大) │ ← 角丸の正方形画像
│      └──────────────┘        │
│ ブラックホール ↗ ◇◇◇◇ ダブルレア│
│ 宇宙 / 月間 120万 閲覧        │
│ 一般相対性理論によって予言…   │
│ ──────────────────────────── │
│ 所持 3枚（出品中 1）          │
│ (還元する 60pt)  (出品する)   │
│ マーケットの最安値 85pt ›     │
└──────────────────────────────┘
```

- 名前の右側に Wikipedia へのアイコンリンクを表示する。リンクの文字と出典・版・ライセンス・画像クレジットの行は表示しない。
- 還元は確認ダイアログで受け取る pt を見せてから実行する。演出として pt の数字がヘッダーの残高へ飛んでいく。
- 「出品する」は出品画面へ進む。所持中（`owned`）の枚数が 0 なら押せない。
- マーケットに同じカードの出品があれば最安値を出し、マーケットの絞り込み結果へ進めるようにする。

## マーケット `/market`

```txt
┌──────────────────────────────┐
│ マーケット            ◎ 1,240pt│
│ [フリマ] [オークション]      │
│ 🔍 カード名で検索            │
│ ジャンル▼ レアリティ▼ 並び順▼│
│ ┌────┐ ブラックホール ◇◇◇◇  │
│ │    │ 85pt                  │
│ └────┘ 出品者 taro          │
│ ┌────┐ 織田信長 ☆           │
│ │    │ 現在 420pt 入札 7件   │
│ └────┘ 残り 2時間13分        │
└──────────────────────────────┘
```

- フリマタブは価格の安い順、新着順で並べ替えられる。
- オークションタブは終了が近い順、入札数の多い順で並べ替えられる。
- 自分の出品は一覧に出すが、購入・入札のボタンは出さない。

## 出品詳細 `/market/$listingId`

- フリマ: 価格と「購入する」ボタン。確認ダイアログで支払う pt と購入後の残高を見せる。
- オークション: 現在価格、残り時間（1秒ごとに更新）、入札履歴、入札額の入力欄。
  - 入力欄の初期値は次に入札できる最低額にする。
  - 入札すると、その額が残高から押さえられることを確認ダイアログで伝える。
  - 抜かれたら押さえは戻る。
- pt が足りないときはボタンが「pt を購入」に変わり、ポイント購入へ進む。

## 出品 `/market/new?userCardId=&cardId=`

```txt
┌──────────────────────────────┐
│ ← 出品                        │
│ ┌────┐ ブラックホール ◇◇◇◇   │
│ └────┘ 最安値 85pt / 還元 60pt│
│ 形式  (●フリマ) (○オークション)│
│ 価格  [   90 ] pt            │
│ 手数料 10%   -9pt            │
│ 受け取り      81pt           │
│ ──────────────────────────── │
│ オークションのとき            │
│ 開始価格 [ 50 ] pt           │
│ 期間 (1日) (3日) (7日)       │
│         ( 出品する )         │
└──────────────────────────────┘
```

- 同じカードの最安値と還元 pt を参考に出し、価格を決めやすくする。
- 手数料と受け取り額は入力に合わせてその場で計算する。
- 出品中のカードは還元できないことを注意書きで出す。

## 出品・入札の管理 `/me/trades`

- 出品中: 取り下げボタン。オークションは入札が入ったら取り下げられない。
- 入札中: 自分が最高額か、抜かれたかを出す。
- 取引履歴: 売れたもの、買ったもの、落札したもの。

## ポイント購入 `/point`

```txt
┌──────────────────────────────┐
│ ポイント購入                  │
│ 残高 1,240pt（有償 1,000 / 無償 240）│
│ ┌──────────────────────────┐ │
│ │ 500pt              $5    │ │
│ ├──────────────────────────┤ │
│ │ 1,000pt            $10   │ │
│ ├──────────────────────────┤ │
│ │ 5,000pt            $50   │ │
│ └──────────────────────────┘ │
│ 特定商取引法に基づく表記 ›    │
│ 資金決済法に基づく表示 ›      │
└──────────────────────────────┘
```

- 商品を選ぶと確認ダイアログを出し、購入すると残高に有償 pt が入る。
  - 決済サービスとの連携は未実装。Stripe Checkout へ移動し、Webhook で付与する形にする予定。いまはローカル開発でだけ、支払いなしで購入できる。本番では商品を押せず「現在 pt は購入できません」と出す。
- 未成年の月額上限に達している場合は購入できない旨を出す。
- 購入前に、pt は払い戻しできないことを表示する。

## 残高履歴・開封履歴

- 残高履歴 `/me/wallet`: `coin_transaction` を新しい順に、種類、増減、残高で出す。有償と無償の内訳も出す。
- 開封履歴 `/me/openings`: 日時、パック、5枚の縮小画像。演出を最後まで見ていない開封があれば「続きを見る」で開封画面へ戻れる。

## 共通の部品

- カード: 角丸の正方形画像の下にタイトルとジャンルを表示する。拡大表示にはレアリティのマークも付ける。枠やホログラムは重ねない。要約と閲覧数は詳細画面に表示する。サイズ違い（一覧用・演出用・拡大用）を1つの部品で出す。
- pt 残高: ヘッダー右上。増減したときに数字がカウントアップする。
- 確認ダイアログ: pt を使う操作、カードを手放す操作は必ず確認を挟む。
