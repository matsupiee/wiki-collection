# Web版とネイティブ版の見た目の一致確認

## 比較方法

Web版を唯一の見本とし、同一アカウント・390×844の表示領域で比較する。React Nativeの実装を保ち、Web版の見た目を変更して差を隠さない。

`NATIVE_SEED_PREFIX=native-parity bun packages/db/src/seed/native-cli.ts` で比較専用利用者を作る。`node scripts/native-parity.mjs 00` で両クライアントを撮影する。画像は `output/native-parity/round-XX` に保存する。`00` は修正前。各回をサブエージェントのレビューから始め、指摘→修正→再撮影→再レビューを繰り返す。実装を担当したエージェントとは別の担当が最終画像を確認する。独立した画面の作業は並行し、回番号は対象画面ごとに記録する。
