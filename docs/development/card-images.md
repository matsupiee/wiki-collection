# カード画像の保存と配信

R・SR・レジェンドの画像は記事を R2 に公開するとき、開発用はローカル seed のときに WebP に変換して保存する。元の Commons URL と作者・ライセンスをカードに保持する。

コモンはパックの支払いと所持カードの登録が成功してから、開封リクエストのバックグラウンド処理で保存する。Worker は Commons の許可された URL とクレジットを検証し、Cloudflare Images バインディングで WebP に変換する。保存処理の失敗で開封結果は失われず、次の取得時に再試行する。

画像を表示する API は R2 に画像があればそれを返し、なければ元 URL に一時転送する。転送はキャッシュしない。R2 のキーは元 URL から計算し、複数のカードに同じ画像があっても共有する。新規に保存する画像の上限は50,000バイト。

環境変数とコマンドは [取り込み手順](./wiki-seed.md) を参照する。
